# Shell Guide

## 可變變量、不可變變量、常量

此三種賦值子的差異呈呈現體現在名稱與修飾符上。變量使用 `snake_case` 風格，而常量則是 `SNAKE_CASE`。  
變量應使用 `local` 於函數內，且僅使用 `local`；常量則於函數外賦值，僅使用 `declare`（可出現於函數內）。

變量不論是否在宣告時立即賦值，只要未加上 `-r` 或 `readonly` 皆為可變變量。  
無論何時都不建議使用 `-a` 宣告為陣列，而是使用 `=()` 同時完成宣告與初始化（如 `local temp_cols=()`），且可在同一個 `local` 指令中宣告多個陣列；`declare -A` 是個例外。  
`declare -r` 應使用 `readonly` 取代。

對於內容大小寫，應該使用 `${test3,,}` 表示小寫或 `${test4^^}` 表示大寫，而不考量在賦值時統一大小寫。  
為加快運算速度及安全性，整數應使用 `-i` 宣告並初始化（如 `local -i k=0`）。

當有多種類型的變量需要宣告，應遵循顯式型別優先於隱式型別的原則，順序為：`-i` > `-n` > `-r` > `-x` > none（純鍵名）。  
範例順序：  
local -i test5=0 test6=1  
local -n out_cols="$2"  
local temp_cols=()  
local test7 test8

若賦值對象為指令時，則必須分兩行賦值，避免賦值吃掉值本身

使用上必須為 `${ ... }` 或 `...` (用於數值運算子)，通常不允許 `$...` 出現，而 `$[\d#*?@]` 不在此限，而對於超過一位以上的動態變量，則使用 `${ ... }`

## 條件子與運算子

對於非純數值條件子，應使用 `[[ ... ]]` 取代 `[ ... ]`，這點體現於現代 Bash Shell 的安全性與可讀性  
而 `[[ ... ]]` 的左側不應加上雙引號 `"`，右側則看情況，同理用在 `(( ... ))` 中，降低視覺噪點  
換句話說，數值運算必須使用 `(( ... ))` 於條件子，`$(( ... ))` 於賦值子之 C 風格運算子  
同時 `-eq`, `-gt`, `-lt`, `=` **絕對**不應該出現在條件子，而是以 `==`, `>`, `<`, `>=`, `<=`, `!=`

## 邏輯子

僅使用 `!`, `&&`, `||`, C 語言邏輯子 (於數值運算子)，也不該出現 `-a`, `-o` 等

當條件為 A 成功，則執行 B，這樣僅需 `if ... fi` 或僅兩個函數時，應改用邏輯子取代，如 command -v git && echo "Founded git"  
而不允許 && / || { ... } 的出現，應改用 `if ... elif ... else ... fi` 或 `case in`

## 完整性

當輸入非整數或布林值時，不論如何都應使用 "" 包裹，這包含陣列，因為屬於多重型別  
路徑則不建議加上，僅在必要時加上，這樣可以確保要麼順利執行，要麼無法執行
